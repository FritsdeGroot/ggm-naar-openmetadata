# 6. Hulpcommando's voor de OpenMetadata API

## Glossary-ID opvragen

De meeste term-gerelateerde endpoints vereisen een UUID, niet de naam:

```bash
GLOSSARY_ID=$(curl -s -H "Authorization: Bearer $OM_JWT_TOKEN" \
  "$OM_HOST/api/v1/glossaries/name/GGM_Objecttypen" \
  | python3 -c "import json,sys; print(json.load(sys.stdin)['id'])")
```

## Alle termen ophalen

```bash
curl -s -H "Authorization: Bearer $OM_JWT_TOKEN" \
  "$OM_HOST/api/v1/glossaryTerms?glossary=$GLOSSARY_ID&limit=1000&fields=name,fullyQualifiedName,parent" \
  > /tmp/om_termen.json

python3 -c "
import json
data = json.load(open('/tmp/om_termen.json'))
terms = data['data']
print('Totaal:', len(terms))
for t in sorted(terms, key=lambda x: x['name'])[:20]:
    print(t['name'])
"
```

> **Let op**: `limit=1000` geeft maximaal 1000 termen terug. Bij meer dan 1000 termen (na laden van objecttypen + attributen) is paginering nodig.

## Specifieke term opzoeken

```bash
# Op naam (FQN)
curl -s -H "Authorization: Bearer $OM_JWT_TOKEN" \
  "$OM_HOST/api/v1/glossaryTerms/name/GGM_Objecttypen.Pand%20(BAG)?fields=relatedTerms,description"

# Child-terms van een objecttype bekijken
curl -s -H "Authorization: Bearer $OM_JWT_TOKEN" \
  "$OM_HOST/api/v1/glossaryTerms?glossary=$GLOSSARY_ID&parent=GGM_Objecttypen.Zaak&limit=100&fields=name"
```

## Zoeken naar termen met specifieke naam

```bash
python3 -c "
import json
data = json.load(open('/tmp/om_termen.json'))
for t in data['data']:
    if 'naam' in t['name'].lower() or 'land' in t['name'].lower():
        print(t['name'], '| parent:', t.get('parent', {}).get('name') if t.get('parent') else None)
"
```

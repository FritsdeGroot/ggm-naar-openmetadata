# 9. De attributenlaag (child glossary terms)

## Waarom child terms?

Met child terms kan een individueel attribuut (bijv. `burgerservicenummer` of `geboorteland`) een eigen PII-classificatie of andere tag krijgen, zonder dat dit het hele objecttype raakt. Attribuut-niveau tagging is niet mogelijk als de attributen alleen als tekst in de objecttype-beschrijving staan.

## Gebruik

```bash
python3 ggm_objecttypen_naar_openmetadata.py --versie v2.5.1 --alle --met-attributen
```

## Wat wordt geladen?

Per attribuut wordt een child Glossary Term aangemaakt met:

- **Type** — het datatype uit de XMI (bijv. `AN80`, `DateTime`, `statusPand`)
- **Definitie** — de GEMMA-definitie indien aanwezig in de XMI
- **Toegestane waarden** — voor kleine, vaste waardelijsten (`uml:Enumeration`), bijv.:

  ```
  **Toegestane waarden:**
  - bouwvergunning verleend
  - bouw gestart
  - pand in gebruik
  - ...
  ```

- **relatedTerms-koppeling** — voor attributen waarvan het type verwijst naar een bestaand objecttype (bijv. `geboorteland` → objecttype `Land`)

## Extractie: `ggm_attributen.json`

De attributen worden door `extract_ggm.py` uit de XMI geëxtraheerd:

- **Bron**: `<attribute>`-elementen in de XMI, gekoppeld via `xmi:idref` aan de `ownedAttribute` van elke class
- **Definitie**: `<documentation value="...">` per attribuut
- **Type**: `<properties type="...">` per attribuut
- **Waardelijsten**: alle `uml:Enumeration`-klassen worden geëxtraheerd; ~510 attributen krijgen een waardelijst
- **Objecttype-referenties**: ~98 attributen krijgen een `relatedTerms`-koppeling naar het verwezen objecttype

## Volgorde-afhankelijkheid van relatedTerms

Een `relatedTerms`-koppeling kan alleen worden gelegd als de doelterm al bestaat. Bij de eerste `--alle`-run kunnen koppelingen naar objecttypen in een later geladen domein mislukken. Een tweede run is zelf-herstellend.

## Objecttypen zonder attributen

135 van de ~947 objecttypen hebben in de XMI geen `ownedAttribute` (abstracte klassen, marker-klassen of specialisaties die attributen erven via een associatie). Deze krijgen geen child-terms — dat is correct gedrag, geen extractiefout.

# 4. Scenario B — Nieuwe GGM-versie (zelfde gemeente)

Dit scenario geldt wanneer Gemeente Delft een nieuwe versie van het GGM publiceert en de OpenMetadata-omgeving moet worden bijgewerkt.

## Stappen

**Stap 1 — Bronbestanden genereren voor de nieuwe versie**

```bash
python3 extract_ggm.py --versie v2.6.0
```

Dit maakt een nieuwe map `data/v2.6.0/` aan met de gegenereerde bronbestanden. Let op naamcollisie-waarschuwingen in de output.

**Stap 2 — Handmatige bronbestanden kopiëren als startpunt**

```bash
cp data/v2.5.1/ggm_definities.json         data/v2.6.0/
cp data/v2.5.1/ggm_pad_naar_domain.json    data/v2.6.0/
cp data/v2.5.1/ggm_naam_disambiguatie.json data/v2.6.0/
```

Controleer daarna:

- **`ggm_pad_naar_domain.json`** — zijn er nieuwe of hernoemde XMI-packagepaden? Voeg mappings toe voor nieuwe paden.
- **`ggm_naam_disambiguatie.json`** — zijn er nieuwe naamcollisies (twee objecttypen met dezelfde naam in verschillende domeinen)? De `extract_ggm.py`-output waarschuwt hier automatisch voor.
- **`ggm_definities.json`** — zijn er nieuwe of gewijzigde domeinen in de GGM README.md?

**Stap 3 — Laden met forceer-omschrijving**

```bash
python3 ggm_naar_openmetadata_domains.py --versie v2.6.0
python3 ggm_objecttypen_naar_openmetadata.py --versie v2.6.0 \
  --alle --met-attributen --met-relaties --forceer-omschrijving \
  2>&1 | tee run_$(date +%Y%m%d_%H%M%S).log
```

De vlag `--forceer-omschrijving` werkt bij al bestaande termen de beschrijving bij als die is gewijzigd.

**Stap 4 — Tweede run voor relatedTerms**

```bash
python3 ggm_objecttypen_naar_openmetadata.py --versie v2.6.0 \
  --alle --met-attributen --met-relaties
```

## Databereiniging na elke XMI-extractie

`extract_ggm.py` voert de volgende opschoning automatisch uit, maar het is goed om te weten welke problemen structureel optreden bij elke XMI-export:

- **Diagram-packages** — pakketten waarvan het pad begint met "Diagram" worden gefilterd (EA-ruis)
- **Null-namen** — objecttypen zonder naam worden verwijderd
- **`::` in namen** — EA-packagenotatie (`Diensten::Aanvraag`) wordt opgeschoond naar `Aanvraag`
- **`/` en `.` in namen** — vervangen door ` of ` resp. verwijderd (conflicteren met FQN-scheidingstekens)
- **Whitespace** — leading/trailing spaties en embedded newlines worden genormaliseerd
